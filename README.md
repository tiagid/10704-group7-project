# 10704-group7-project (Project Pennsylvania)

CEN3031 Software Engineering, Fall 2026, University of Florida.

Authors: Brady O'Connor, Vincent Schifano, Daniel Tiagi

A web app that turns recorded audio into a MIDI file. Upload a WAV or MP3 or record from the mic, and the app detects the notes and returns a .mid file you can open in any DAW or notation software.

Daniel is Scrum Master and QA lead, Brady leads the backend, Vincent leads the frontend. Everyone works across the whole project.

backend/ holds the Python transcription pipeline. frontend/ holds the React web interface.
